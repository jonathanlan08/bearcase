# docs/design

Design source of truth for BearCase AI, produced with the UI/UX Pro Max skill and refined by hand.

1. `creative-direction.md` — identity, concept (Ink and Paper), qualities, anti-patterns, decisions to preserve
2. `design-system.md` — color, status glyphs, typography, layout, shape, materials, icons, component tokens
3. `landing-page-spec.md` — public route map and section specifications
4. `application-spec.md` — app route map, shell, seven views, states, keyboard map
5. `motion-system.md` — tokens, vocabulary, choreography, reduced motion
6. `3d-evidence-sculpture.md` — the layered-sheets hero: story chapters, geometry, textures, camera, lighting, quality tiers, fallbacks
7. `responsive-behavior.md` — breakpoints and per-view behavior
8. `accessibility.md` — WCAG 2.2 AA requirements and testing gates
9. `performance-budget.md` — budgets and practices
10. `component-inventory.md` — component list and acceptance checklist
